распознавание речи, а видео — через тот же энкодер картинок, что уже работает.

- [ ] **Картинки для Cyber-Tiel и Ornith-abl.** Движок их уже читает на пути `--pack`; у этих моделей картинки выключены,
  потому что их не проверяли. Подключить энкодер (у Cyber-Tiel — `mmproj-BF16.gguf` из репозитория модели, у Ornith-abl
  — mmproj bartowski от обычного Ornith) с закреплёнными ревизией и SHA-256, собрать `strata-vision`, проверить на
  скриншотах кода, схемах и фото с текстом по API OpenAI и Anthropic. Энкодер — на процессоре (видеопамяти нет).
- [ ] **Звук, фаза 0: замер.** Скорость GigaAM v3 (русский) и Parakeet-TDT-0.6B-v3 (английский и смесь) на i9-14900K и
  насколько распознавание на соседних ядрах замедляет генерацию Strata.
- [ ] **Звук, фаза 1: распознавание речи в сервере** (по флагу, по умолчанию выключено):
  - `/v1/audio/transcriptions` как у OpenAI;
  - `input_audio` в чате и в Responses API (в том числе форма `audio_url`, которую шлёт Codex) — расшифровка
    подставляется в запрос текстом;
  - исправить ошибку: сейчас `serve/frontend.py` молча выбрасывает звук из запроса, и модель отвечает, не услышав;
  - направить распознавание Hermes (`STT_OPENAI_BASE_URL`) на свой сервер.
- [ ] **Видео, режим записи экрана.** Без правки движка: кадры при смене экрана как картинки с метками времени плюс
  расшифровка звука.
- [ ] **Видео, нативный режим Qwen3.6.** Кодирование кадров парами в `strata-vision`, метка `<t seconds>` перед
